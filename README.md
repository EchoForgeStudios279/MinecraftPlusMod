# Minecraft+

Minecraft+ is a community-driven Minecraft mod that expands the vanilla
experience with new content and mechanics while keeping the general
Minecraft style.

> Minecraft+ is currently in early development.

## Supported Versions

| Minecraft | Fabric | NeoForge |
|-----------|--------|----------|
| 1.21.1    | ✅     | ✅       |

## Features

### Potions

- Potion of Haste
- Potion of Resistance

More features will be added over time.

## Installation

### Fabric

Requires:
- Minecraft 1.21.1
- Fabric Loader
- Fabric API

### NeoForge

Requires:
- Minecraft 1.21.1
- NeoForge

## Development

Minecraft+ is developed as a MultiLoader project.

The project is split into:

- `common` – shared Minecraft+ code
- `fabric` – Fabric-specific code
- `neoforge` – NeoForge-specific code

Java 21 is required.
